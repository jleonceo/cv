Proyecto destacado

Sistema de control económico con IA · TechAcces

MySQL Power BI DAX Python n8n Claude Code MCP Evals LLM

Empresa simulada de comercio electrónico que monté como laboratorio: los datos son ficticios y el sistema funciona de verdad.

  • Base de datos contable en MySQL con el Plan General Contable: cerca de 19.000 registros en 19 tablas, con 6.399 asientos y 17.399 líneas de 2023 a julio de 2026, cuadrados al céntimo sobre 22 millones por lado.
  • Modelo de Power BI con 77 medidas DAX. Las cifras del cuadro de mando se contrastan al céntimo con una consulta SQL independiente.
  • 55 skills, seis de ellas de terceros o adaptadas, para contabilidad, tesorería, control interno, análisis de datos, marketing y programación, coordinadas por un enrutador que decide cuál entra en cada tarea.
  • Cinco agentes contables con permisos separados: el que lee la factura no propone el asiento, el que lo verifica no puede escribir y el único que escribe lo hace en una tabla de borradores. El paso al libro diario lleva human in the loop.
  • Servidor MCP propio con seis herramientas contables. La IA entra con un usuario de base de datos que no tiene permiso para borrar.
  • Evaluación continua: 24 skills con evals ejecutadas y sus resultados guardados, y 681 bancos de pruebas automáticos. Cada control se prueba también con casos que tienen que fallar.
  • Reporting en el que la IA no calcula ninguna cifra: motores en Python de antigüedad de saldos, ratios y previsión de caja con backtesting, que vuelcan sus resultados en MySQL.
  • Entrada de facturas de proveedor por correo automatizada con n8n y diseñada con una guía de 19 fases, que fija qué hace la IA, qué hace el código y quién aprueba. Hoy en fase piloto.

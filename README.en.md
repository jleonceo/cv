# CV · Juan Luis León Rodríguez

A professional CV in HTML/CSS, ready to print on A4 or to view in a browser. The CV itself is in Spanish.

## Why a CV lives here

A CV in a closed document gets sent and then lost from sight. Nobody knows what the version from six months ago
said, you cannot link to a specific line, and every touch-up creates another file with another name.

Publishing it as a repository changes three things. The full history stays, so every change has a date and a reason.
There is a stable address to point to. And what it claims can be checked against the rest of the account, which is
where the work it mentions lives.

In exchange, the privacy of sending it is lost: whatever is published can be read by anyone, including the contact
details further down.

## Contents

`index.html`: a single file with the text, the styles and the chart data inside. It depends on two external
resources that are downloaded when it opens, the Google Fonts typefaces and the [Chart.js](https://www.chartjs.org/)
library from a CDN, so **without a connection the text can be read in full and the two charts come out blank**.

## How to view it

Open `index.html` in any browser. To save it as a PDF: `Ctrl+P` → "Save as PDF" → A4 size.
